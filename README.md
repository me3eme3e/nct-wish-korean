# 한국어 노트. — NCT WISH Edition

iPadを主な利用端末とする、ログイン不要の韓国語学習PWAです。

## データ保存について
- 単語帳、学習済み項目、動画メモ、メンバー別メモはブラウザの `localStorage` に保存します。
- データは基本的に利用中のiPad・ブラウザ内に残り、アカウントやサーバー同期は使いません。
- SafariのWebサイトデータ消去、プライベートブラウズ、端末故障などで消える可能性があります。「単語帳」画面からJSONバックアップを定期的に保存してください。
- 同じURLでもSafariとホーム画面アプリの保存領域が別になる場合があります。最初にホーム画面版で使い始めるのがおすすめです。

## 公開方法（無料枠のある静的ホスティング）
1. このZIPを展開します。
2. GitHubに新しいリポジトリを作成し、展開したファイル一式をアップロードします。
3. Vercelにログインし、GitHubリポジトリをImportしてDeployします。
4. 発行された `https://...vercel.app` のURLをiPadのSafariで開きます。
5. Safariの共有ボタン →「ホーム画面に追加」→「追加」。

PWAのインストールとService WorkerにはHTTPSが必要です。VercelはHTTPSのURLを提供します。

## ローカルで確認
`python3 -m http.server 8000` をこのフォルダで実行し、ブラウザで `http://localhost:8000` を開きます。

## 現在の範囲
- 歌詞の学習例文、公式YouTubeへのリンク、リスニング例文、6人のメンバー別メモ、TOPIKミニクイズ、単語帳、JSONバックアップ。
- 実際の動画字幕の自動取得、音声認識、AI添削、公式歌詞の全文表示、複数端末同期は含みません。
- NCT WISHの名称は学習対象を示すために使用しています。公式提携・公式アプリではありません。
